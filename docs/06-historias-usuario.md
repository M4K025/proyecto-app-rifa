# 06 — Historias de usuario (ordenadas)

Tus notas literales, redactadas como HU para programar:

1. Como usuario necesito una app para **crear una rifa**.
2. Como usuario quiero **colocar el objeto de mi rifa con sus datos** (nombre, tamaño, color, usado, foto/video, contacto).
3. Como usuario necesito **registrar la lotería que voy a utilizar** (números, fechas, precio).
4. Como participante necesito **registrarme a una rifa** (elegir número).
5. Como participante necesito un apartado para **registrar mis datos de contacto** (nombre, correo, teléfono, documento).
6. Como usuario necesito un apartado para **visualizar los números disponibles** (disponible / apartado / pagado / rechazado).
7. Como organizador necesito **ver lo recaudado vs meta $2.000.000** y exportar reporte.
8. Como organizador necesito **realizar el sorteo** y publicar ganador.

Criterios mínimos del MVP (lo que programa el demo actual): HU 1, 4, 5, 6 + pago pendiente→aprobado.
